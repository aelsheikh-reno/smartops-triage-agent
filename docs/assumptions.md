# Assumptions register

Status: living document. Every row is an assumption the design depends on and that has not been measured yet. When a row is tested, record the result and the date, and update the design decision it feeds. Section numbers refer to `docs/design-decisions.md`.

Source types: **estimate** (a number someone guessed), **reasoning** (follows from how the systems work, not measured), **public doc** (stated in vendor documentation, cited).
