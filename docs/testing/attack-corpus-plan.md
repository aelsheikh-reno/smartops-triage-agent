# Attack-corpus plan for the lab

Generated from `tests/corpus/plan.yaml` by `tests/corpus/render_plan.py`; edit the YAML, not this page.

The replay gate proves a detection against public true-positive data; the lab adds real alerts from the customer's stack shape (Splunk ES, Sysmon, Windows event logs, FortiGate). This plan lists, for every detection, the ATT&CK techniques, the Atomic Red Team tests that should fire it, public datasets that cover it, the data it needs, and whether the lab can produce it today.

## The lab

Has: Splunk ES; Sysmon and Windows event logs through the universal forwarder; FortiGate (traffic, IPS, web filter); Atomic Red Team; Cribl (replays samples); Windows Defender Antivirus on the Windows hosts (built in).

Lacks: EDR; email gateway; DLP product; WAF.

## Lab case format

Where: tests/corpus/cases/<D-ID>/<lab run ID>.yaml (one normalized alert per file, after anonymisation).

Required: `detection`, `source`, `lab_run_id`, `anonymisation_done`, `license`, `alert`, `expect`.

| Field | Meaning |
|---|---|
| `detection` | D-ID |
| `source` | lab (a Reno lab run), cribl_synth (a Cribl-synthesised vendor alert, with the sample it was built from), or a public dataset (repo and path) |
| `lab_run_id` | the lab run that produced it: date, lab host set and Atomic Red Team test GUID (for example 2026-11-02-lab1-873106b7) |
| `anonymisation_done` | true only after host names, user names, IP addresses, domains and any customer-like data are replaced with neutral values; the method used goes in anonymisation_method |
| `anonymisation_method` | how it was anonymised (for example the lab's fixed replacement table) |
| `license` | the licence the case is under: internal for lab runs, the dataset's licence for public samples |
| `alert` | the normalized alert the normalizer produced (roles only, no raw vendor event) |
| `expect` | outcome, at least flag (a true positive never closes) |

Never committed: raw lab logs, packet captures, EVTX files, malware or driver samples and Cribl source samples; only the anonymised normalized case is committed (tests/corpus/.gitignore keeps raw/ and samples/ out).
