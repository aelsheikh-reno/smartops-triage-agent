Triage Agent Onboarding

From kickoff to production in about three months. Month 1 builds the customer’s context and runs the agent in Shadow, where it triages but nobody sees its verdicts. After that, each detection earns more autonomy on its own track record, so “production” never means every alert is automatic.

Numbered boxes are one-time steps. Dashed bars are processes that start in that phase and keep running. Lettered lines are gates: the next phase starts only when the gate passes. For what happens to a single alert, see the Triage Agent Workflow.
